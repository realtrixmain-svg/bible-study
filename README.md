# Bible Study Notes

Personal Bible study notes managed in [Obsidian](https://obsidian.md).

## Structure

| Folder      | Contents                         |
|-------------|----------------------------------|
| `Books/`    | Notes organized by book of Bible |
| `Topics/`   | Topical studies                   |
| `People/`   | Character studies                 |
| `Daily/`    | Daily devotionals / journaling    |
| `Templates/`| Obsidian templates                |

## Workflow

1. Open this folder as an Obsidian vault
2. Create or edit notes using Markdown
3. Commit and push changes to back up to GitHub
